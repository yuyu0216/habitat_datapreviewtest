# 結局圖表預覽（5/25 資料）

回合結算 / 遊戲結束時，要給小學生看的「物種與棲地逐回合變化」圖表預覽。
**此資料夾只是預覽與探索，沒有改動任何系統程式。** 挑好版型後再決定要把哪幾張接進系統。

## 怎麼看

直接用瀏覽器打開 `round-charts-preview.html` 即可（純前端、可離線、無外部套件）。
- 上方分頁切換 **老師端（全班總覽）** / **玩家端（我的故事）**
- 玩家端可用下拉選單換玩家；也支援網址參數：`?p=S08#player` 直接開某位玩家

## 8 種版型一覽

### 老師端（全班 12 人總覽）
| 代號 | 名稱 | 形式 | 建議用途 |
|---|---|---|---|
| A1 | 全班生態系全景 | 物種堆疊長條 | 看「整體變多/變少 + 誰最多」，主畫面首選 |
| A2 | 六族群命運線 | 折線 | 比較「誰一直衝、誰被壓、誰最後摔下來」 |
| A3 | 四大棲地小卡 | 4×堆疊長條 | 討論「每塊地被誰佔據、怎麼變」 |
| A4 | 棲地擁擠度熱力圖 | 矩陣熱力圖 | 一眼看「哪塊地擠爆超載了」 |

### 玩家端（單一玩家自己的歷程）
| 代號 | 名稱 | 形式 | 建議用途 |
|---|---|---|---|
| B1 | 我的成長曲線 | 面積折線 | 最直覺的「我長大了多少」 |
| B2 | 我的棲地版圖 | 棲地堆疊長條 | 看「我從住一塊地擴張到好幾塊」 |
| B3 | 我 vs 全班 | 對比折線 | 我跟同色夥伴 / 全班平均比 |
| B4 | 我的故事時間軸 | 卡片時間軸 | **最貼合主軸**：人類做了什麼 → 我怎麼變 |

## 資料怎麼來的

- 原始：`../habitat-export-2026-05-25T10-11-16/`（player_state.csv + reports.csv）
- `build-data.js`：一次性解析 CSV → 產出 `data.json`（人看的）→ 轉成 `data.js`（HTML 載入用）
- 若要換成別場資料：改 build-data.js 的 SRC 路徑，`node build-data.js`，再把 data.json 轉成 data.js

## 設計重點（呼應教學主軸）

「人類干預才是因，物種都是果」── 所以每張圖都把**人類開發事件**放進來：
老師端頂部有「人類事件時間軸」（農藥→廢水→砍伐→工廠廢水→生態崩潰），
B4 玩家時間軸更是一回合一張卡，把「因（人類行為）」直接接到「果（我的數量變化）」。
資料本身就講了完整故事：前 5 回大家拼命長大，第 5 回人類造成生態崩潰，所有族群同時銳減。
